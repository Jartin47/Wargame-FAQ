# Wargame FAQ — OTS Class 27-05 Quick Reference

A searchable, single-page quick reference for the OTS wargames:

- MCE grading and leadership (L1–L7, brief and debrief formats)
- Operation Pacific Shield (OPS), including CSpOC and MEDCOM
- AFEX
- Operation Crimson Scorpion
- Operation Black Strike (WOC)
- MFR format and the team's MFR library

Built only from the team's own course files; every entry names its source document.

## Use it

Open `index.html` in any browser (no internet needed), or enable GitHub Pages on this repo (Settings → Pages → Deploy from branch → `main` / root).

- Press `/` to jump to search, `Esc` to clear.
- Search matches every word you type, across all games.
- Filter by game with the buttons under the search bar.
- Links keep your search: `index.html?q=forklift&g=ops`.
